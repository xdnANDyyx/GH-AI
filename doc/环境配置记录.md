### 九、快速启动步骤

```bash
# 1. 确保 MySQL 和 Redis 服务已启动

# 2. 编译后端
cd C:\Guanghe\img-ai
C:\Guanghe\tools\apache-maven-3.9.16\bin\mvn clean package -DskipTests

# 3. 启动后端
java -jar ruoyi-admin/target/ruoyi-admin.jar

# 4. 安装前端依赖（需先切换到 Node 16）
nvm use 16.20.2
cd ruoyi-ui
npm install

# 5. 启动前端开发服务器
npm run dev
```
