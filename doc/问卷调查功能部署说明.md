# 问卷调查功能部署说明

## 功能概述

用户在登录超过5次或生成图片超过10次后，登录时会弹出问卷调查弹窗，收集用户信息以优化服务。

## 部署步骤

### 1. 执行数据库脚本

按顺序执行以下SQL脚本：

```bash
# 1. 创建问卷调查表
mysql -u用户名 -p密码 数据库名 < sql/user_survey_questionnaire.sql

# 2. 更新用户表添加统计字段
mysql -u用户名 -p密码 数据库名 < sql/update_sys_user_for_survey.sql
```

**注意**：如果sys_user表已经存在login_count、image_generate_count、survey_completed字段，第二步会报错。可以手动执行：

```sql
ALTER TABLE sys_user 
ADD COLUMN login_count INT DEFAULT 0 COMMENT '登录次数' AFTER `update_time`,
ADD COLUMN image_generate_count INT DEFAULT 0 COMMENT '图片生成次数' AFTER `login_count`,
ADD COLUMN survey_completed TINYINT DEFAULT 0 COMMENT '是否已完成问卷调查（0:未完成 1:已完成）' AFTER `image_generate_count`;
```

### 2. 后端编译部署

```bash
# 进入后端项目目录
cd ruoyi-admin

# 编译项目
mvn clean package -DskipTests

# 启动服务
java -jar target/ruoyi-admin.jar
```

### 3. 前端编译部署

```bash
# 进入前端项目目录
cd guanghe-studio

# 安装依赖
npm install

# 编译项目
npm run build

# 将dist目录部署到Nginx或其他Web服务器
```

## 功能说明

### 触发条件

用户需要同时满足以下条件才会弹出问卷：

1. **未完成问卷**：`survey_completed = 0`
2. **达到触发阈值**：`login_count >= 5` 或 `image_generate_count >= 10`

### 问卷内容

1. **公司名称**（选填）
2. **公司规模**（必填）
   - 1-20人
   - 20-50人
   - 50-100人
   - 100人以上
3. **每月上新产品数量**（必填）
   - 1-20
   - 20-50
   - 50-100
   - 100+
4. **每月制作图片数量**（必填）
   - 100张以内
   - 100-500张
   - 500-2000张
   - 2000+
5. **希望新增功能**（必填，多选）
   - 视频生成
   - 爆款分析
   - AI文案
   - 自动排版
   - 品牌模板
   - 一键翻译
   - 团队协作
   - API接口
   - PSD导出
   - 其他（可文字输入）
6. **联系方式**（选填）

### 用户操作

- **提交**：用户填写问卷后点击提交，数据保存到数据库
- **跳过**：用户可以选择跳过问卷，下次登录仍会弹出

## 后续需要实现的功能

### 1. 登录次数统计

在登录成功后增加登录次数。需要修改以下文件：

**文件**：`ruoyi-framework/src/main/java/com/ruoyi/framework/web/service/SysLoginService.java`

在登录成功的方法中添加：

```java
// 更新用户登录次数
SysUser user = new SysUser();
user.setUserId(loginUser.getUserId());
user.setLoginCount(loginUser.getLoginCount() + 1);
userService.updateUserLoginCount(user);
```

### 2. 图片生成次数统计

在图片生成成功后增加生成次数。需要修改以下文件：

**文件**：`ruoyi-admin/src/main/java/com/ruoyi/web/controller/customer/CustomerAiImageController.java`

在`generateOmniImage`方法中，生成成功后添加：

```java
// 更新用户图片生成次数
SysUser user = new SysUser();
user.setUserId(loginUser.getUserId());
user.setImageGenerateCount(user.getImageGenerateCount() + 1);
userService.updateUserImageGenerateCount(user);
```

### 3. 用户Service添加方法

需要在`SysUserService`中添加以下方法：

```java
/**
 * 更新用户登录次数
 */
int updateUserLoginCount(SysUser user);

/**
 * 更新用户图片生成次数
 */
int updateUserImageGenerateCount(SysUser user);
```

并在Mapper中添加对应的SQL语句。

### 4. 问卷提交后更新用户状态

在`CustomerSurveyController`的`submitSurvey`方法中，提交问卷后需要更新用户的`survey_completed`状态：

```java
// 更新用户问卷完成状态
SysUser user = new SysUser();
user.setUserId(loginUser.getUserId());
user.setSurveyCompleted(1);
userService.updateUserSurveyCompleted(user);
```

## 注意事项

1. **管理员用户不触发问卷**：在`App.vue`中已经判断`!userStore.isAdmin`，管理员用户不会看到问卷弹窗

2. **问卷只弹一次**：用户提交问卷后，`survey_completed`字段会标记为1，下次登录不会再弹出

3. **跳过功能**：用户点击跳过，问卷会关闭，但下次登录仍会弹出（因为未提交问卷）

4. **数据安全**：问卷数据通过JSON格式存储多选功能，确保数据完整性

5. **性能考虑**：问卷状态检查在`onMounted`时执行一次，不会频繁请求后端

## 问题排查

### 问卷不弹出

1. 检查用户是否已完成问卷：`SELECT survey_completed FROM sys_user WHERE user_id = ?`
2. 检查登录次数和图片生成次数是否达到阈值
3. 查看浏览器控制台是否有报错
4. 检查后端接口是否正常：`GET /customer/survey/status`

### 问卷提交失败

1. 检查网络请求是否成功
2. 查看后端日志是否有异常
3. 验证数据库表结构是否正确
4. 检查必填项是否都已填写
