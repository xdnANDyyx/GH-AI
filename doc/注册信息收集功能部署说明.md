# 注册信息收集功能部署说明

## 功能概述

在用户注册时收集基本信息，包括岗位、主营平台、了解渠道和使用目的，以便更好地了解用户需求。

## 功能说明

### 注册表单字段

用户在注册时需要填写以下信息：

#### 1. 基本信息（必填）

**岗位**（单选）
- 老板/负责人
- 运营
- 设计师
- 美工
- 摄影
- 采购
- 其他（可文字输入）

#### 2. 主营平台（必填，多选）
- Amazon
- Wayfair
- Walmart
- Shopify
- TikTok Shop
- 淘宝
- 天猫
- 京东
- 拼多多
- Shopee
- Lazada
- 独立站
- 其他（可文字输入）

#### 3. 了解渠道（必填，多选）
- 抖音
- 小红书
- 微信
- Google
- 百度
- 朋友推荐
- 展会
- 其他（可文字输入）

#### 4. 使用目的（必填，多选）
- 白底图
- 换背景
- 产品精修
- AI模特
- 主图
- 详情/A+
- Banner
- 尺寸图
- 批量生成

### 数据存储

所有多选字段以JSON格式存储到数据库：
- `platforms` - 主营平台数组
- `channels` - 了解渠道数组
- `purposes` - 使用目的数组

"其他"选项的文本内容分别存储在：
- `position_other` - 岗位其他
- `platform_other` - 平台其他
- `channel_other` - 渠道其他

### 提交流程

1. 用户填写注册信息（账号、密码、验证码）
2. 填写基本信息（岗位、主营平台、了解渠道、使用目的）
3. 点击注册按钮
4. 前端先调用注册接口创建账号
5. 注册成功后，自动提交注册信息
6. 注册信息保存到 `user_register_info` 表

### API接口

#### 提交注册信息
```
POST /customer/register/info/submit
Request Body:
{
  "position": "设计师",
  "positionOther": "",
  "platforms": "[\"Amazon\",\"淘宝\"]",
  "platformOther": "",
  "channels": "[\"抖音\",\"朋友推荐\"]",
  "channelOther": "",
  "purposes": "[\"白底图\",\"换背景\"]"
}
```

#### 获取注册信息
```
GET /customer/register/info/info
Response:
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "userId": 123,
    "position": "设计师",
    "platforms": "[\"Amazon\",\"淘宝\"]",
    "channels": "[\"抖音\",\"朋友推荐\"]",
    "purposes": "[\"白底图\",\"换背景\"]"
  }
}
```

## 注意事项

1. **注册信息可选**：虽然前端有验证，但如果用户注册时未提交注册信息，不影响账号创建

2. **数据更新**：如果用户已经存在注册信息，再次提交会更新现有记录

3. **JSON格式**：多选字段以JSON数组格式存储，查询时需要注意解析

4. **权限控制**：注册信息接口需要登录后才能访问，但注册时用户还未登录，需要特殊处理

## 后续优化建议

1. **注册时自动登录**：注册成功后自动登录，提升用户体验

2. **信息补全**：允许用户在个人中心补全或修改注册信息

3. **数据分析**：在管理后台添加注册信息统计分析功能

4. **字段扩展**：根据业务需要可以添加更多收集字段

5. **验证优化**：可以添加手机号验证、邮箱验证等

## 问题排查

### 注册信息未保存

1. 检查浏览器控制台是否有报错
2. 查看后端日志是否有异常
3. 验证数据库表是否创建成功
4. 检查网络请求是否成功

### 数据格式错误

1. 检查JSON格式是否正确
2. 查看数据库字段长度是否足够
3. 验证特殊字符是否处理

### 表单验证不通过

1. 检查必填项是否都已填写
2. 查看验证规则是否正确
3. 确认表单数据绑定是否正确
