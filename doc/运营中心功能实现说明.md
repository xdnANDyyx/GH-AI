# 运营中心功能实现说明

## 实现概述

本次开发完成了后台管理系统的运营中心模块，包括 **Banner管理** 和 **官方素材管理** 两大功能板块。

---

## 1. Banner管理

### 1.1 功能特性

#### Banner列表
- ✅ 表格展示：标题、预览缩略图、投放位置、状态、点击量、创建时间
- ✅ 支持按标题、投放位置、状态筛选
- ✅ 状态标签：已发布（绿色）、已下架（灰色）、定时发布（橙色）
- ✅ 批量删除功能

#### 创建/编辑Banner
- ✅ 弹窗表单设计
- ✅ 图片上传：支持拖拽上传，限制5MB，支持JPG/PNG/GIF
- ✅ 标题、链接地址输入
- ✅ 投放位置选择：首页、工作流、积分页
- ✅ 排序设置（数字越小越靠前）
- ✅ 定时发布：支持设置开始时间和结束时间（精确到分钟）
- ✅ 状态切换：已发布/已下架/定时发布

#### 点击统计
- ✅ 点击趋势图展示
- ✅ 支持近7天/近30天/近3个月维度查看
- ✅ 柱状图可视化，带数值标签
- ✅ 空数据状态提示

### 1.2 技术实现

#### 后端实现
**实体类**: `BssBanner.java`
```
- id: Banner ID
- title: 标题
- imageUrl: 图片URL
- linkUrl: 跳转链接
- position: 投放位置（0=首页, 1=工作流, 2=积分页）
- sort: 排序
- clickCount: 点击次数
- status: 状态（0=已发布, 1=已下架, 2=定时发布）
- startTime: 开始时间
- endTime: 结束时间
```

**数据库表**: `bss_banner`（已创建）

**Service接口**: `IBssBannerService.java`
- 标准CRUD操作
- 状态变更
- 点击趋势统计（按日期范围聚合）

**Controller接口**: `BannerController.java`
- `GET /business/banner/list` - 分页查询
- `GET /business/banner/{id}` - 详情
- `POST /business/banner` - 新增
- `PUT /business/banner` - 修改
- `DELETE /business/banner/{ids}` - 删除
- `PUT /business/banner/status/{id}/{status}` - 状态变更
- `GET /business/banner/clickTrend/{id}` - 点击趋势（支持startDate/endDate参数）

#### 前端实现
**API接口**: `src/api/ops/banner.js`
- 完整的CRUD接口封装
- 点击趋势查询接口

**页面组件**: `src/views/ops/banner/index.vue`
- 搜索表单区
- 数据表格（含缩略图、状态标签）
- 新增/编辑对话框（含图片上传）
- 点击趋势对话框（柱状图展示）

**菜单配置**: SQL脚本已创建
- 菜单路径: `/ops/banner`
- 权限标识: `ops:banner:*`

## 2. 官方素材管理

### 2.1 功能特性

#### 素材列表
- ✅ 网格视图：卡片式展示，含缩略图、名称、类型、状态
- ✅ 列表视图：表格展示，含详细信息、标签、上传时间
- ✅ 视图切换按钮（网格/列表）
- ✅ 多维度筛选：素材名称、类型、标签、状态
- ✅ 批量操作：批量删除、批量发布/下架

#### 上传/编辑/删除
- ✅ 批量上传素材（支持多文件）
- ✅ 编辑素材：名称、类型、标签（多选）、描述
- ✅ 删除确认机制
- ✅ 图片预览功能

#### 标签管理
- ✅ 独立标签管理对话框
- ✅ 标签列表展示
- ✅ 新增/编辑/删除标签
- ✅ 标签关联素材数量统计
- ✅ 删除前关联检查

#### 发布/下架
- ✅ 单个素材状态切换
- ✅ 批量发布/下架
- ✅ 状态标签：已发布（绿色）、已下架（灰色）

### 2.2 技术实现

#### 后端实现
**实体类**:
1. `BssOfficialMaterial.java` - 素材主表
```
- id: 素材ID
- name: 素材名称
- fileUrl: 文件URL
- thumbnailUrl: 缩略图URL
- materialType: 素材类型（0=图片, 1=视频, 2=3D模型, 3=其他）
- description: 描述
- fileSize: 文件大小
- status: 状态（0=已发布, 1=已下架）
```

2. `BssMaterialTag.java` - 标签表
```
- id: 标签ID
- tagName: 标签名称
- sort: 排序
```

3. `BssMaterialTagRelation.java` - 素材标签关联表
```
- materialId: 素材ID
- tagId: 标签ID
```

**数据库表**: `bss_official_material`, `bss_material_tag`, `bss_material_tag_relation`（已创建）

**Service接口**:
- `IBssOfficialMaterialService.java` - 素材CRUD + 批量操作
- `IBssMaterialTagService.java` - 标签管理
- `IBssMaterialTagRelationService.java` - 关联关系管理

**Controller接口**:
1. `OfficialMaterialController.java`
   - `GET /business/material/list` - 分页查询（含标签关联）
   - `GET /business/material/{id}` - 详情
   - `POST /business/material` - 新增
   - `PUT /business/material` - 修改
   - `DELETE /business/material/{ids}` - 删除
   - `PUT /business/material/status/{id}/{status}` - 状态变更
   - `PUT /business/material/batchStatus` - 批量状态变更

2. `MaterialTagController.java`
   - `GET /business/material/tag/list` - 标签列表
   - `POST /business/material/tag` - 新增标签
   - `PUT /business/material/tag` - 修改标签
   - `DELETE /business/material/tag/{ids}` - 删除标签

#### 前端实现
**API接口**:
- `src/api/ops/material.js` - 素材API
- `src/api/ops/materialTag.js` - 标签API

**页面组件**: `src/views/ops/material/index.vue`
- 搜索表单区（含标签多选）
- 视图切换按钮
- 网格视图组件（卡片布局）
- 列表视图组件（表格布局）
- 新增/编辑素材对话框（含文件上传、标签多选）
- 标签管理对话框（独立弹窗）

**菜单配置**: SQL脚本已创建
- 菜单路径: `/ops/material`
- 权限标识: `ops:material:*`, `ops:material:tag:*`

## 4. 功能演示路径

### 4.1 Banner管理演示
1. **列表查看**: 运营中心 → Banner管理
2. **新增Banner**: 点击「新增」→ 上传图片 → 填写信息 → 选择位置 → 保存
3. **编辑Banner**: 点击「编辑」→ 修改信息 → 保存
4. **查看统计**: 点击「统计」→ 切换时间范围 → 查看趋势图
5. **状态切换**: 切换状态开关 → 确认
6. **删除Banner**: 勾选 → 点击「删除」→ 确认

### 4.2 官方素材管理演示
1. **列表查看**: 运营中心 → 官方素材管理
2. **视图切换**: 点击右上角网格/列表图标切换视图
3. **上传素材**: 点击「上传素材」→ 选择文件 → 填写信息 → 选择标签 → 保存
4. **标签管理**: 点击「标签管理」→ 新增/编辑/删除标签
5. **编辑素材**: 网格视图点击卡片或列表视图点击「编辑」→ 修改信息 → 保存
6. **批量操作**: 勾选多个素材 → 批量发布/下架/删除
7. **筛选搜索**: 使用顶部搜索表单 → 按名称/类型/标签/状态筛选

## 5. 注意事项

### 5.1 权限配置
确保用户角色已分配以下权限：
- `ops:banner:*` - Banner管理全部权限
- `ops:material:*` - 素材管理全部权限
- `ops:material:tag:*` - 标签管理全部权限

### 5.2 文件上传配置
确认 `application.yml` 中文件上传配置正确：
```yaml
# 文件上传配置
file:
  upload:
    path: /path/to/upload  # 上传路径
    prefix: http://yourdomain.com  # 访问前缀
```

### 5.3 字典配置
系统已自动创建以下字典：
- `banner_position` - Banner投放位置（首页/工作流/积分页）
- `material_type` - 素材类型（图片/视频/3D模型/其他）

可在「系统管理 → 字典管理」中查看和调整。
